## 7. 简历项目经历版本

### 7.1 简历标题

FitPlanAI：基于大模型的减脂训练与轻食规划 AI Agent

### 7.2 一句话介绍

基于 LLM 与多模态识别能力，设计并开发面向减脂用户的个性化训练、营养摄入和轻食烹饪规划 Agent，支持身体数据建档、营养目标计算、训练计划生成、食材图片识别和多轮对话式方案调整。

### 7.3 项目描述

```text
FitPlanAI 是一个面向健身减脂场景的 AI Agent 项目，用户输入身高、体重、体脂率、肌肉量、训练频率、目标周期等身体数据后，系统自动计算每日热量、蛋白质、碳水和脂肪摄入目标，并生成个性化训练计划与饮食建议。项目支持用户拍摄现有食材，调用多模态模型识别食材种类，结合用户当日剩余营养目标生成轻食菜谱、烹饪步骤和营养估算。
```

### 7.4 项目职责

```text
1. 负责项目需求分析和系统架构设计，拆分用户建档、营养计算、训练计划、食材识别、轻食生成和反馈调整等核心模块。
2. 设计基于 Agent 的多轮对话流程，支持缺失信息追问、食材重量确认、伤病/忌口校验和计划动态调整。
3. 设计营养计算规则，根据用户身体数据和目标周期估算 TDEE、热量缺口，并计算蛋白质、碳水、脂肪等每日摄入目标。
4. 接入多模态图片识别能力，识别用户上传的食材照片，并将识别结果结构化为食材名称、预估重量、置信度和待确认状态。
5. 设计结构化输出 Schema，规范训练计划、饮食建议、轻食菜谱、营养估算和风险提醒的返回格式，提升大模型输出稳定性。
6. 规划食材营养库、训练动作库和健康风险规则库，为后续 RAG 检索和个性化推荐提供数据基础。
```

### 7.5 项目亮点

```text
1. 将大模型能力落地到健身减脂垂直场景，覆盖“建档-规划-执行-反馈-调整”的完整业务闭环。
2. 采用 Agent 工作流设计，将营养计算、食材识别、菜谱生成、训练计划生成拆分为可调用工具，提升系统可维护性和可扩展性。
3. 引入多模态识别能力，支持用户通过拍照输入现有食材，并结合营养目标生成可执行轻食方案。
4. 使用结构化输出约束模型返回内容，确保热量、蛋白质、碳水、脂肪、动作组数等关键字段可被前端和数据库稳定消费。
5. 设计健康风险提醒机制，对极低热量、伤病动作、过度训练、过敏源和忌口进行规则校验。
```

## 8. 面试可讲故事线

### 8.1 为什么做这个项目

我是健身教练兼营养师，发现很多用户不是缺少减脂意愿，而是缺少可执行的计划。他们常见问题是“不知道该吃多少蛋白质、不知道现有食材怎么做成减脂餐、不知道训练计划如何根据身体数据调整”。所以我设计了 FitPlanAI，把我的专业知识和大模型 Agent 能力结合，做一个能自动建档、规划、解释和调整的减脂助手。

### 8.2 技术挑战

- 用户输入不完整，需要 Agent 主动追问。
- 大模型输出容易发散，需要结构化输出约束。
- 食材图片识别存在误差，需要用户确认重量和食材。
- 营养规划不能只靠大模型生成，需要结合确定性计算规则。
- 健康建议有安全边界，需要风险校验和免责声明。

### 8.3 解决方案

- 用 Agent 工作流拆分建档、计算、生成、确认、调整步骤。
- 用 Pydantic/JSON Schema 约束模型输出。
- 把营养素计算做成独立工具，保证关键数值可解释。
- 食材识别后进入确认流程，再生成轻食方案。
- 引入健康风险规则库，拦截极端饮食和高风险训练建议。
