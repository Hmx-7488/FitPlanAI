## 俯卧撑标准
标准要点：身体一条直线，核心收紧，臀部夹紧。
俯卧撑是最基础的上肢推力训练，适合所有训练水平。

## 常见错误与纠正
常见错误：塌腰、手肘过度外展。
纠正方法：斜面俯卧撑降低难度、死虫式激活核心。
塌腰会导致腰椎代偿，增加下背部受伤风险。
