# 常见力量训练动作标准与纠错

## 深蹲
标准要点：双脚与肩同宽或略宽，脚尖外展15-30度。
下蹲时膝盖方向与脚尖一致，臀部向后向下坐。
背部保持平直，核心收紧，重心在脚掌中部。
下蹲至大腿平行或略低于膝盖。
常见错误：膝盖内扣、弓腰、重心前移、蹲不够深。
纠正方法：弹力带辅助激活臀中肌、箱式深蹲练习。

## 硬拉
标准要点：双脚与髋同宽，杠铃贴近身体。
启动前收紧核心，肩胛后收下沉，脊柱中立。
以髋关节为主导发力，杠铃贴身上行。
常见错误：腰椎弯曲、杠铃离身体太远。
纠正方法：罗马尼亚硬拉练习、降低重量重建动作模式。

## 卧推
标准要点：肩胛后收下沉，双脚踩实地面。
杠铃下放至胸部中下部，手肘与躯干约45-75度。
常见错误：肩胛松动、手肘过度外展、臀部离凳。
纠正方法：地板卧推练习、暂停卧推。

## 俯卧撑
标准要点：身体一条直线，核心收紧，臀部夹紧。
常见错误：塌腰、手肘过度外展。
纠正方法：斜面俯卧撑降低难度、死虫式激活核心。

## 引体向上
标准要点：肩胛先下沉再发力拉起，下巴过杆。
常见错误：耸肩代偿、大幅摆动、半程动作。
纠正方法：弹力带辅助、离心引体练习。
