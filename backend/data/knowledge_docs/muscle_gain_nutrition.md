# 增肌期营养与训练原则

## 热量盈余
增肌需要热量盈余，即摄入大于消耗。
推荐盈余幅度：TDEE的5%-15%（约200-500kcal）。
每周体重增加0.25-0.5kg为合理范围。

## 蛋白质需求
增肌期蛋白质需求：每公斤体重1.8-2.4g。
每餐摄入30-50g蛋白质，分4-5餐摄入。

## 碳水化合物
碳水是训练的主要能量来源。
训练日碳水摄入应高于休息日。
增肌期碳水可占总热量45%-55%。

## 训练原则
渐进超负荷：逐步增加重量、组数或次数。
每肌群每周12-20组有效训练。
复合动作为主：深蹲、硬拉、卧推、划船、推举。
每4-6周安排一个减载周。
