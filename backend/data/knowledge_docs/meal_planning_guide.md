# 宏量营养素与餐次安排

## 餐次分配原则
减脂期：3-4餐，热量均匀分配或训练日午餐偏多。
增肌期：4-6餐，训练前后各安排一餐含碳水的正餐或加餐。
每餐间隔3-4小时，保持血糖稳定。

## 训练前后饮食
训练前1-2小时：摄入易消化碳水+少量蛋白质（如香蕉+酸奶）。
训练后30-60分钟：快速吸收蛋白质+碳水。

## 常见食材替换
蛋白质替换：鸡胸肉可替换为鱼肉、虾仁、瘦牛肉、豆腐。
主食替换：白米饭可替换为糙米、红薯、玉米、燕麦。
蔬菜替换：西兰花可替换为菠菜、芦笋、生菜、黄瓜。
