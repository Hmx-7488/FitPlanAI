# 中国饮食习惯与减脂方案

## 地域饮食特点
南方：米饭为主食，菜式清淡，多蒸煮。
北方：面食为主，口味偏咸，炖菜较多。
川湘：口味重辣重油，需注意烹饪用油量。
粤式：清蒸白灼为主，整体较健康。

## 外卖点餐建议
优先选择：轻食沙拉、少油盖饭、清汤麻辣烫。
点餐技巧：米饭减半、酱汁分开、少油少盐。
麻辣烫选择清汤底，多选瘦肉、豆制品和蔬菜。

## 食堂就餐建议
选择两荤一素搭配半碗米饭。
优选清蒸、白灼、炖煮类菜品。
可自带鸡胸肉或鸡蛋补充蛋白质。

## 便利店方案
优选：无糖豆浆、茶叶蛋、全麦三明治、酸奶、坚果。
蛋白质不足时可选：即食鸡胸肉、蛋白棒。

## 家常快手菜（15分钟内）
番茄炒蛋、蒜蓉西兰花、白灼虾、清蒸鱼。
鸡胸肉切片快炒蔬菜、豆腐汤。

## 备餐建议
15分钟方案：鸡胸肉+西兰花+糙米，提前煮好分装。
30分钟方案：可多做1-2种菜品冷藏。
