# 减脂期蛋白质摄入

## 蛋白质需求范围
减脂期蛋白质需求高于维持期，因为热量缺口下身体更容易分解肌肉。
推荐范围：每公斤体重1.6-2.2g蛋白质。
力量训练者建议取上限（2.0-2.2g/kg）。

## 蛋白质分配策略
每餐摄入20-40g蛋白质，分3-5餐摄入。
训练后30-60分钟内摄入20-40g蛋白质，促进肌肉修复。

## 高蛋白食材参考
动物蛋白：鸡胸肉（31g/100g）、鸡蛋（13g/100g）、牛肉（26g/100g）。
植物蛋白：豆腐（8g/100g）、鹰嘴豆（19g/100g）。
乳制品：希腊酸奶（10g/100g）、牛奶（3.3g/100ml）。

## 注意事项
肾功能异常者需遵医嘱调整蛋白质摄入。
高蛋白饮食需增加饮水量。
