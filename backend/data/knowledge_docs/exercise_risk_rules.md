# 运动动作风险规则

## 膝关节伤病禁忌
避免动作：深蹲大重量、跳跃类动作、长跑。
替代动作：臀桥、臀推、坐姿腿弯举、椭圆机。
深蹲建议：限制深度、降低重量、使用护膝。

## 腰椎伤病禁忌
避免动作：大重量硬拉、仰卧起坐、俄罗斯转体。
替代动作：平板支撑、死虫式、鸟狗式。
硬拉建议：降低重量、保持脊柱中立。

## 肩关节伤病禁忌
避免动作：颈后推举、直立划船、大重量侧平举。
替代动作：绳索面拉、俯身飞鸟、弹力带外旋。

## 高冲击动作风险
体重过大者（BMI大于30）避免跑步、跳跃。
替代：椭圆机、游泳、划船机、骑车。
