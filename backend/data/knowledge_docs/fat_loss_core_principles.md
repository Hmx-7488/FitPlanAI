# 减脂核心原则

## 热量缺口
减脂的核心是热量缺口，即消耗大于摄入。
安全的热量缺口：每日300-500kcal。
对应每周减重约0.3-0.5kg。
极端热量缺口（大于1000kcal）会导致肌肉流失和代谢下降。

## 基础代谢率(BMR)
推荐使用Mifflin-St Jeor公式：
男性：BMR = 10 x 体重(kg) + 6.25 x 身高(cm) - 5 x 年龄 + 5
女性：BMR = 10 x 体重(kg) + 6.25 x 身高(cm) - 5 x 年龄 - 161

## 活动系数与TDEE
久坐（几乎不运动）：BMR x 1.2
轻度活动（每周1-3次运动）：BMR x 1.375
中度活动（每周3-5次运动）：BMR x 1.55
高度活动（每周6-7次运动）：BMR x 1.725
极高活动（体力劳动或专业运动员）：BMR x 1.9
TDEE = BMR x 活动系数
减脂目标热量 = TDEE - 热量缺口(300-500kcal)

## 三大营养素分配
蛋白质：减脂期每公斤体重1.6-2.2g，力量训练者取上限，每g蛋白质4kcal。
脂肪：不低于总热量20%，优先选择不饱和脂肪，每g脂肪9kcal。
碳水化合物：剩余热量由碳水补充，优先选择复合碳水，每g碳水4kcal。

## 膳食纤维与饮水
每日膳食纤维建议25-30g，增加饱腹感促进消化。
每日饮水量 = 体重(kg) x 30-40ml，运动日额外补充500-1000ml。
