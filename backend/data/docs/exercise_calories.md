## 减脂运动建议
1. 有氧运动建议心率控制在最大心率的60%-70%，脂肪燃烧效率最高
2. 最大心率估算：220 - 年龄
3. 力量训练能提高基础代谢率，减脂期必须配合力量训练
4. 每周建议：3-4次力量训练 + 2-3次有氧，每次45-60分钟
5. 运动前后注意热身和拉伸，防止受伤
6. 体重较大者优先选择低冲击运动：游泳、椭圆机、骑车
7. 运动消耗因人而异，表中数据仅供参考
